# builds/dev/

Ready-to-run Windows development environment. All services bind to localhost only.

| Item | Purpose |
| --- | --- |
| `server-windows/` | Compiled Windows server with its data and config. |
| `client-legacy-windows/` | Compiled Windows legacy client with assets. |
| `client-redemption-windows/` | Redemption client, once its foundation is ready. |
| `database/` | Local database setup and initialization. |
| `setup.bat` | First-time setup (database, accounts). *Planned.* |
| `start-server.bat` | Launches the server. *Planned.* |
| `start-client.bat` | Launches the client. *Planned.* |
