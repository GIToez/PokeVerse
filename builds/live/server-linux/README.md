# builds/live/server-linux/

Linux live server package (`pokeverse-server-linux.tar.gz`), built by the **Live server**
workflow (artifact `PokeVerse-Server-Linux-Live`) with `scripts/live/package-linux-server.sh`.
It holds no passwords or secrets; those exist only on the server.

Deployment and setup: [`docs/live-server.md`](../../../docs/live-server.md).
