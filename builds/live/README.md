# builds/live/

Release packages for players and the production server. Live clients connect to the live
server; see [`docs/live-server.md`](../../docs/live-server.md).

| Folder | Target | Status |
| --- | --- | --- |
| `server-linux/` | Production game server (Linux, OVH). | Built by **Live server** |
| `client-legacy-windows/` | Legacy client for Windows. | Built by **Windows dev package** (`PokeVerse-Windows-Live`) |
| `client-legacy-linux/` | Legacy client for Linux. | Planned |
| `client-redemption-windows/` | Redemption client for Windows. | Phase 3 |
| `client-redemption-linux/` | Redemption client for Linux. | Phase 3 |
| `client-redemption-android/` | Redemption client for Android. | Phase 3 |
| `client-redemption-web/` | Redemption client for web browsers. | Phase 3 |

The legacy client has no Android or web version; those platforms are Redemption only.
