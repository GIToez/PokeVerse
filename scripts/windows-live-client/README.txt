PokeVerse - Windows client
==========================

This client connects to the PokeVerse live server (@SERVER@).

1. Extract the whole zip, for example to C:\PokeVerse. Do not run it from inside the zip.
2. Double-click pokeverse-client.exe.
3. Click "Create Account" to make an account, then "New Character" to create your trainer.
   New characters start in Professor Oak's tutorial.

Requirements: Windows 10 or 11 (64-bit) and a graphics card with OpenGL 2.0 support.

The server restarts once a day; you are warned in game 30 minutes before. Your progress is
saved automatically.
