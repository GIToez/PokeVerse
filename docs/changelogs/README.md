# Player changelogs

Every changelog posted to Discord is saved here, one file per post date (`YYYY-MM-DD.md`), as it
was published. The next changelog starts where the last one stopped.

- Each file says which commit on `main` it covers up to.
- The text is for players: only what they will see or notice in game. Staff tools, Discord bot
  setup, tests and art that isn't in the game yet stay out.
- Each post is in its own block, under Discord's 2,000-character limit, so it can be pasted as
  is.
- Post a changelog only once the client release and the server deploy it describes are out.
